# CoreTech — ERP + E-Commerce Frontend

A Filipino-style IT tools shop made as a BSIT frontend school project.

## Interfaces
1. Customer e-commerce: products, search, cart, checkout demo, orders.
2. Admin ERP: dashboard, products, inventory, orders, customers, suppliers, sales, reports.

## Current term
No real database, backend, authentication server, or payment gateway. Product information is JavaScript mock data. Cart and demo order use browser localStorage.

## Future term
Frontend → Backend/API → Database. Suggested tables: users, products, categories, inventory, suppliers, orders, order_items, customers, purchases, sales.

## Product images
The product image areas are intentionally blank in this version. Add image files to each `images` folder and set the matching `image` filename in `js/data.js`.
